# Bridget Lin Portfolio

A single-page portfolio that presents selected projects as a small, scrollable art gallery. View the live site: https://linbridget.github.io/portfolio/

## Features

- Project carousel with descriptions, technologies, and project details
- Multi-select skill filters that show projects matching any selected skill
- Responsive gallery layout

## Project Structure

- `index.html` contains the page content and semantic structure.
- `styles.css` defines the visual design and responsive layouts.
- `script.js` contains the project data, carousel, and skill-filter behavior.
- `.github/workflows/pages.yml` deploys the site to GitHub Pages.

## Local Preview
